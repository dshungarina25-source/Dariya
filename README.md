1. Какую проблему решает проект?
Многим людям сложно контролировать свои ежедневные траты. Данное приложение позволяет быстро записывать расходы по категориям и сразу видеть наглядную статистику. Это помогает экономить и планировать бюджет.
2. Функционал (Что умеет приложение)
* Добавление данных: Ввод суммы и выбор категории из списка.
* Сохранение: Данные не стираются при закрытии, так как хранятся в формате JSON.
* Визуализация: Автоматическое построение таблицы и графиков (Bar Chart).
* Защита: Проверка на пустой ввод или нулевые значения.
3. Технический стек
* Python — основной язык.
* Streamlit — создание интерфейса.
* Pandas — обработка данных в таблицы.
* JSON — база данных.
